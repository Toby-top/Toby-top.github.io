将 Apple Music 的诡异ロマジ 还原成仮名 和漢字　
#

Apple Music 經常將日文歌曲羅馬拼音化，或將中韓歌曲名強行翻譯成英文，甚至乎廣東歌都變埋英文。JiBA 專為解決這一核心痛點而生，幫你找回原汁原味的元數據。
–JiBA 官网

各位如果有用 Apple Music 听日文歌想必都十分理解这这个痛： 点开歌单，准备听首歌，结果发现歌单里的歌都变成了一堆奇怪的日文罗马字。想听春日影了，屏幕上却出现 Haruhikage, SilhouetteDance, Meisekiha, Mayoiuta… 这都什么啊！！！[满屏幕 片假名 罗马音鬼看得懂啊.jpg] (翻桌)

今年一月的某日在推特(现 X)上进行愉快冲浪时，发现关注的 ⁣凍檸茶走冰走檸走茶走甜唔該 也深受同样问题的困扰， ta 还开发了一款工具，名字叫 JiBA (Japanese is Back Again)，择日不如撞日，我马上就去下载来学习使用了。

虽然这个名字有点搞，但这真的是一个认真研发的工具，它的原理就是通过匹配歌曲的唯一 ID，找到原数据，再对“错误”的数据进行替换，如此便能将歌名与歌手都能变成自己能看懂的汉字了，然后通过 iCloud 同步资料库到其他所有平台，使得同一 id 的其他设备也能看见正常的元数据。JiBA UI 简洁，新手友好十分易上手，可惜的是只有 macOS 版本。

官网链接：
https://jiba.hee.ink

如果你的电脑上有 Homebrew, 这是更加推荐的安装方式，只需在终端执行以下命令：

brew install --cask jiba

改进了 blog 写作工作流
#

和以前一样，也是在 VSCode 利用 markdown 进行写作，但是现在为 blog 的源码创建了个新的 GitHub 仓库，可以利用 Git 进行多端同步，再也不是只局限在 MacBook 上进行写作了。

Not by AI 贴纸
#

想必大家都注意到了，我在最新的几篇博文后面加上了一个小小的贴纸，这也是在推特愉快冲浪的时候，看见了一篇介绍这个贴纸的文章，什么时候看见的，谁发的我都忘了。不过我依旧记得其传递的中心主旨：AI 依靠人类创作的内容进行训练，如果全人类都依靠 AI 创作内容，全世界的内容都会变得重复，冗余，停滞不前。

在 AI 横行的年代，世界依旧需要有人创作新内容，个人 blog 不为流量而生，不为吸引多少人，创造多少收入。只为创造一个小小的空间，一个能够存放我独特思想的空间，留下我来过这个地球的证据；同时像是在一座孤岛上，向着不知多远的远方发射信号，发射寻找同频灵魂之信号。
写上面这行字的时候我又想起了一句话：

出淤泥而不染，濯清涟而不妖
–《爱莲说》

Not by AI，我想这是个人博客存在的意义。
